Why a program store

Gear that says Ocotillo Tennis, not just gym.

The club shop carries a great everyday line. This store is different: it is built for the tennis program only, with the pieces players actually wear on court and to the clubhouse. Quarter-zips and polos for pros and league captains, hoodies and tees for juniors, and a player name on the back so every kid feels like part of the team.

Rounds reopen for each season: fall leagues, spring juniors, summer camps. Same link, fresh gear, and the program earns on every order.
